# Contribution Guidelines

Please note that this project is released with a [Contributor Code of Conduct](code-of-conduct.md). By participating in this project you agree to abide by its terms.

## What belongs here

- Free resources for the foreign exchange market: data, libraries, charting, backtesting, broker APIs, calendars and learning material.
- Paid services only when their free tier or documentation is useful on its own, and the entry says what is free.
- Maintained projects: no archived, deprecated or undocumented ones, and nothing without an update in about two years unless it is still the standard tool and the entry says updates are rare.
- No signal sellers, no "guaranteed" or "proven" returns, no affiliate links, no performance claims, nothing blockchain-related.

## How to add an entry

- One pull request per entry, added at the bottom of its section.
- Format: `- [Name](link) - Description.` The description is one honest sentence: it starts with a capital letter, ends with a period, says what the resource is and, where it matters, its catch (rate limits, unofficial, Windows only, check the data's terms).
- Link to GitHub projects with `#readme` at the end.
- Say in the pull request why it is worth listing and what you used it for.
- If you work on the project you add, say so in the pull request.

## Entries from the maintainers

The maintainers run the Forexia network (InterestRateDecision.com, Forexia, TradingSignalBot, PropSim, OpenCharts). Their own entries follow the same rules, sit after the alternatives in each section, and say "by the maintainers of this list".

## Updating or removing

If a link is dead, a project is abandoned or a better alternative exists, open an issue or a pull request. The link checker runs every week and opens an issue for broken links.
